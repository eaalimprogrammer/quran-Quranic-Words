# Quranic Words — تحليل كلمات القرآن الكريم

خط معالجة **حتمي وقابل للتدقيق** لنص المصحف الشريف، مبني على قاعدتين:

1. **النص المصدر لا يُعدَّل أبداً.** كل تطبيع يحصل في طبقة مشتقّة، مش في النسخة الأصلية.
2. **كل رقم قابل للتتبّع** لقاعدة صريحة موثّقة. ولو القاعدة فيها خلاف بين العلماء، بتتعرض أكتر من نتيجة من غير ترجيح.

---

## النتائج الأساسية

| البيان | العدد | القاعدة |
|---|---:|---|
| السور | 114 | عناوين `سورة` |
| الآيات | 6,236 | عدّ حفص/الكوفي |
| إجمالي الكلمات | 77,794 | فصل بالمسافات، الآيات فقط |
| كلمات مختلفة (بالتشكيل) | 17,576 | نفس الحروف ونفس التشكيل |
| كلمات مختلفة (بدون تشكيل) | 14,872 | نفس الحروف، التشكيل غير فارق |
| كلمات وردت مرة واحدة | 8,711 | hapax legomena |

**المصدر رسم إملائي (مش عثماني)** — ثبت ده على مستوى الـ codepoint: صفر ظهور لـ `ٱ` (U+0671) والألف الخنجرية (U+0670) وعلامات الوقف (U+06D6–06DC) وعلامة نهاية الآية (U+06DD).

## الملفات

### السكربتات

| الملف | الوظيفة |
|---|---|
| `quran_analyzer.py` | خط المعالجة الكامل: استخراج ← هيكلة ← بوابة تحقق ← تطبيع ← تقطيع ← تحليل تكراري |
| `build_by_surah.py` | بناء ملف الكلمات مرتّب سورة بسورة |
| `build_surah_files.py` | تقسيم لـ 114 ملف، ملف لكل سورة |
| `verify_tracker.py` | فحص سلامة أي ملف متابعة مقابل المصحف (9 فحوصات) |

### المخرجات (`output/`)

كل اللي في `output/` **مولّد بالكامل** من `quran.docx` بالسكربتات — يعني قابل لإعادة التوليد في أي وقت.

- `quran_corpus.csv` — الكوربوس المهيكل (6,236 صف)
- `quran_words_by_surah.csv` — الكلمات مرتّبة سورة بسورة
- `surah_files/` — 114 ملف، ملف لكل سورة
- `word_frequency_*.csv` — جداول التكرار للصور الأربع
- `codepoint_inventory.csv` — سجل تدقيق يونيكود (59 codepoint)
- `review_needed.csv` — حالات تحتاج قرار بشري
- `summary_report.md` — التقرير الكامل بكل الأرقام والتحفّظات

## بوابة التحقق

الخط بيرفض يكمل لو أي فحص فشل، **ومبيصلّحش أي حاجة تلقائياً**:

```
[✓] عدد الصفوف = 17,576        [✓] مفيش كلمة مكررة
[✓] الترقيم متسلسل 1..N        [✓] كل كلمة موجودة في القرآن
[✓] مفيش كلمة ناقصة            [✓] مجموع التكرارات = 77,794
[✓] التكرارات مطابقة للمصحف     [✓] كل المواضع حقيقية
```

**دليل خارجي على صحة الطريقة:** سورة الفاتحة بتطلع **29 كلمة** — وهو العدد المتوارث المعروف لها.

## شذوذان في المصدر — مسجّلان ولم يُصلَحا

- **الحجر 15:99** — نص الآية موجود كامل، بس علامة `(99)` ناقصة. اتستُنتجت حدود الآية من نهاية السورة؛ **مفيش نص اتخلق**.
- **الهمزة 104** — البسملة غايبة من المصدر (السورتين 103 و105 عندهم بسملة). **لم تُعوَّض**.
